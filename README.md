# Street Scrap Tycoon — Living Survival Update

This build adds the living-survival layer requested:

- Separate Hunger meter that decreases with in-game time.
- Low hunger can reduce health.
- Sleeping on the Streets is less restorative and adds survival pressure; owned housing improves recovery.
- Carrying a very full backpack increases fatigue/energy pressure.
- Random minor accidents and sudden-weather effects can affect health/energy during time-consuming activity.
- Eating a proper meal restores hunger, health and a little energy.
- New Filipino-life consumables: Pandesal, Banana Cue, Calamansi Energy Drink, First-Aid Kit.
- Consumable Use buttons in the Backpack; inventory still hides zero-quantity items.
- Quick Snack action for Pandesal/Banana Cue.
- Local dispatch contracts refresh as the day/period changes and are tailored to the current district.
- Existing contract expiry/accept/reject logic remains intact.
- Existing randomized market, NPC schedules, auctions, production, establishments, phone, dev tools, save/load, story and roadmap systems are preserved.

Open `index.html` in a modern browser.
